# Theme Editor Overview

The Shopify Theme Editor is where you customize your store's appearance. Here's a quick orientation.

## Layout

- **Left sidebar** — Lists all sections on the current page. Click a section to edit it.
- **Center preview** — Live preview of your store. Changes appear in real-time.
- **Top bar** — Switch between pages (Homepage, Product, Collection, etc.)

## Key Concepts

### Sections
Sections are the building blocks of each page. You can add, remove, reorder, and configure them. Atelier includes 16 custom sections like Hero Banner, Shop the Look, and Featured Collection.

### Blocks
Some sections contain blocks — repeatable items within a section. For example, the Testimonials section has testimonial blocks, and the Marquee section has text blocks.

### Color Schemes
Every section can use one of 5 color schemes. This lets you create visual contrast between sections without custom CSS.

## Adding a Section

1. Click **Add section** at the bottom of the sidebar
2. Browse or search for the section you want
3. Click it to add it to your page
4. Drag to reorder if needed

## Saving Changes

Click **Save** in the top-right corner. Changes are not live until you save and publish the theme.
