# Product Page Setup

The product page displays your product details, media, variants, and add-to-cart functionality.

## Key Features

- **Media gallery** — Supports images, video, 3D models, and external video
- **Variant selector** — Dropdown or button-style variant pickers
- **Quantity selector** — Increment/decrement buttons
- **Add to cart** — Primary action button
- **Description** — Full product description with rich text support
- **Vendor, type, SKU** — Optional product metadata
- **Share button** — Native sharing functionality
- **Pickup availability** — Shows if available for local pickup

## Image Recommendations

- **Product photos:** 1000×1000px minimum (square or portrait)
- **Format:** JPEG or WebP for photos
- **Background:** White or neutral for product shots, lifestyle for context
- Shopify generates responsive sizes automatically

## Tips

- Upload multiple product images — customers want to see every angle
- Add a lifestyle image alongside product-only shots
- Write detailed descriptions — they help with SEO and customer confidence
