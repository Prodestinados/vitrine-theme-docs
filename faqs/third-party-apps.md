# Third-Party Apps

## Does Atelier work with Shopify apps?

Atelier is compatible with most Shopify apps. Apps that use Shopify's App Blocks (Online Store 2.0) integrate seamlessly.

For apps that inject custom code, add them via the **Custom Liquid** section or through theme code editing.

If an app isn't displaying correctly, check if it requires theme-specific configuration or contact the app developer.
