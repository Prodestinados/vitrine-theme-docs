# Updating the Theme

## How do I update Atelier to a new version?

1. Download the latest version ZIP file
2. Go to **Online Store → Themes**
3. Click **Add theme → Upload ZIP file**
4. Upload the new version
5. Review the new theme in preview mode
6. When ready, click **Publish** to make it live

> **Important:** Uploading a new theme version creates a separate copy. Your customizations from the old version won't carry over automatically. Re-apply your settings in the new version before publishing.

Check the [Changelog](../changelog/v1-0-0.md) for what's changed in each version.
