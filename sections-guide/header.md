# Header

The header appears on every page and contains your logo, navigation, search, account, and cart icons.

## Settings

| Setting | What it does |
|---------|-------------|
| **Logo** | Upload your brand logo |
| **Logo width** | Display width: 50–250px (default 120px) |
| **Menu** | Select your main navigation menu |
| **Sticky header** | Keep header visible while scrolling (default: on) |
| **Color scheme** | Scheme 1–5 |

## Tips

- Enable sticky header so customers can always access navigation
- Keep your logo width proportional — 100–150px works well for most logos
- Create your menu in **Online Store → Navigation** before configuring the header
