# Editorial Split

A two-column layout pairing a full-height image with editorial text content. Great for brand storytelling.

## Settings

| Setting | What it does |
|---------|-------------|
| **Image** | The editorial image |
| **Subheading** | Small text above the heading |
| **Heading** | Main headline (default: "The Edit") |
| **Heading size** | Small, Medium, Large |
| **Text** | Rich text content |
| **Button** | Label, link, and style (primary/secondary/link) |
| **Layout** | Image first (left) or Text first (right) |
| **Text alignment** | Left or Center |
| **Full width** | Extend to edges (default: on) |
| **Color scheme** | Scheme 1–5 |

## Image Recommendations

- **Dimensions:** 900×1200px minimum (portrait orientation)
- **Style:** Editorial or lifestyle photography
- **Format:** JPEG, under 500KB

## Tips

- Use Scheme 2 (Warm) or Scheme 3 (Dark) for visual contrast
- "Full width" on gives the section a more immersive feel
- Keep text concise — let the image do the heavy lifting
