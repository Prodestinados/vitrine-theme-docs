# Rich Text & Custom Liquid

## Rich Text

A centered text section for brand messaging, announcements, or storytelling.

### Settings

| Setting | What it does |
|---------|-------------|
| **Subheading** | Small text above heading |
| **Heading** | Main heading (default: "Talk about your brand") |
| **Heading size** | Small, Medium, Large |
| **Text** | Rich text content |
| **Button** | Label, link, and style |
| **Text alignment** | Left or Center |
| **Color scheme** | Scheme 1–5 |

### Tips

- Use with a dark color scheme for a bold statement section
- Keep text concise — this section is for impact, not long-form content

---

## Custom Liquid

A code block for merchants who want to add custom HTML, CSS, or Liquid.

### Settings

| Setting | What it does |
|---------|-------------|
| **Liquid code** | Your custom Liquid/HTML code |
| **Color scheme** | Scheme 1–5 |

### Tips

- Use for embedding third-party widgets, custom banners, or unique layouts
- Test your code in the Theme Editor preview before publishing
