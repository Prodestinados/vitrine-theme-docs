# Collection List

Display collection cards in a responsive grid. Perfect for showcasing your store's categories.

## Settings

| Setting | What it does |
|---------|-------------|
| **Heading** | Section heading (default: "Collections") |
| **Heading size** | Small, Medium, Large |
| **Columns** | 2, 3, or 4 columns (default 3) |
| **Image ratio** | Portrait, Square, or Landscape |
| **Color scheme** | Scheme 1–5 |

## Collection Card Blocks

Up to **8 blocks**. Each block:

| Setting | What it does |
|---------|-------------|
| **Collection** | Select the collection |
| **Image** | Override collection image |
| **Title** | Override collection title |

## Tips

- Use square or landscape ratio for collection cards
- Override images when collection featured images don't match your aesthetic
