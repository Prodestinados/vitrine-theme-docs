# Image with Text

A versatile two-column section with an image alongside text content.

## Settings

| Setting | What it does |
|---------|-------------|
| **Image** | Section image |
| **Image ratio** | Adapt, Portrait, Square, or Landscape |
| **Subheading** | Small text above heading |
| **Heading** | Main heading |
| **Heading size** | Small, Medium, Large |
| **Text** | Rich text content |
| **Button** | Label, link, and style |
| **Layout** | Image first or Text first |
| **Text alignment** | Left or Center |
| **Color scheme** | Scheme 1–5 |

## Tips

- Use "Adapt" image ratio to preserve the image's natural proportions
- Alternate layout direction between sections for visual variety
