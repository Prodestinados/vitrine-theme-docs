# Buttons

Atelier supports three button styles, configurable per-section.

## Button Styles

| Style | Appearance |
|-------|-----------|
| **Primary** | Filled button with accent color background |
| **Secondary** | Outlined button with border |
| **Link** | Text-only link with no background or border |

## Global Settings

In **Theme Settings → Buttons**:

| Setting | What it does |
|---------|-------------|
| **Button border radius** | Corner rounding for all buttons |

### Preset Defaults

| Preset | Border Radius |
|--------|--------------|
| Atelier | 0px (square) |
| Runway | 0px (square) |
| Salon | 40px (pill-shaped) |

## Tips

- Button colors come from the section's color scheme
- Most sections let you choose button style per CTA
