# Collage

An asymmetric grid mixing images, products, and collections for an editorial lookbook feel.

## Settings

| Setting | What it does |
|---------|-------------|
| **Heading** | Section heading |
| **Heading size** | Small, Medium, Large |
| **Layout** | Left large or Right large |
| **Color scheme** | Scheme 1–5 |

## Content Blocks

Up to **3 blocks**. Mix and match:

| Block | Settings |
|-------|----------|
| **Image** | Image, heading text, link URL |
| **Product** | Product picker |
| **Collection** | Collection picker |

## Tips

- Use 3 blocks for the best visual balance
- Mix block types — e.g., one lifestyle image + one product + one collection
- The "Left large" layout makes the first block dominant
