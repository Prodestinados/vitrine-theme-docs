# Featured Collection

Display products from a selected collection in a responsive grid.

## Settings

| Setting | What it does |
|---------|-------------|
| **Heading** | Section heading (default: "Featured collection") |
| **Heading size** | Small, Medium, Large |
| **Collection** | Select the collection to display |
| **Products to show** | Number of products: 2–12 (default 4) |
| **Columns** | Grid columns: 2, 3, or 4 (default 4) |
| **Image ratio** | Portrait (3:4), Square (1:1), or Landscape (4:3) |
| **Show vendor** | Display product vendor name |
| **Show secondary image** | Show alternate image on hover |
| **Show "View all"** | Link to full collection page |
| **Color scheme** | Scheme 1–5 |

## Tips

- Use portrait ratio for fashion — it shows clothing best
- 4 columns works well on desktop; it automatically adjusts to 2 on mobile
- Enable secondary image for an interactive hover effect
