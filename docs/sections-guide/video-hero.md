# Video Hero

A full-width video section with text overlay. Supports Shopify-hosted video, YouTube, and Vimeo.

## Settings

| Setting | What it does |
|---------|-------------|
| **Video** | Shopify-hosted video file |
| **Video URL** | YouTube or Vimeo URL |
| **Poster image** | Fallback image shown before video loads |
| **Subheading** | Small text above heading |
| **Heading** | Main heading (default: "In Motion") |
| **Heading size** | Small (h1), Medium (h0), Large (hxl) |
| **Button** | Label, link, and style |
| **Content position** | 6-point grid (middle/bottom × left/center/right) |
| **Text alignment** | Left or Center |
| **Section height** | Medium, Large, or Full-screen |
| **Overlay opacity** | 0–100% |
| **Color scheme** | Scheme 1–5 |

## Tips

- Videos autoplay muted and loop — they're background ambiance
- Always provide a poster image for slower connections
- Set overlay to 30–40% so text is readable over video
- Use Shopify-hosted video for best performance; YouTube/Vimeo embed via iframe
