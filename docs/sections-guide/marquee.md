# Marquee

An infinite-scrolling text banner for announcements, promotions, or brand messaging.

## Settings

| Setting | What it does |
|---------|-------------|
| **Text size** | Small (h6), Medium (h4), Large (h2) |
| **Speed** | Scroll speed: 5–60 seconds per cycle (default 20s) |
| **Direction** | Scroll left or right |
| **Separator** | Between items: dot, dash, star, or none |
| **Color scheme** | Scheme 1–5 |

## Content Blocks

Unlimited blocks. Each block is either:

| Block | What it does |
|-------|-------------|
| **Text** | A scrolling text item |
| **Image** | A small inline image |

## Tips

- Add 3–5 text blocks for varied messaging (e.g., "Free shipping", "New season", "Shop the collection")
- Lower speed values = faster scrolling
- Star separator adds a fashion-editorial feel
- Place between the hero and product sections for a visual break
