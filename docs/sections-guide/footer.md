# Footer

The footer appears on every page and can contain menus, text, newsletter signup, social icons, and payment icons.

## Settings

| Setting | What it does |
|---------|-------------|
| **Show newsletter** | Display email signup form (default: on) |
| **Show social** | Display social media icons (default: on) |
| **Show payment icons** | Display accepted payment methods (default: on) |
| **Show country selector** | Currency/country picker (default: on) |
| **Show language selector** | Language picker (default: on) |
| **Color scheme** | Scheme 1–5 |

## Content Blocks

| Block | What it does |
|-------|-------------|
| **Menu column** | A navigation menu with heading |
| **Text column** | Free-form text content with heading |

Up to 4 blocks. Each menu block needs a menu created in **Online Store → Navigation**.

## Tips

- Add 2–3 menu columns for organized footer navigation (Shop, Company, Support)
- Use a text block for your brand story or store description
