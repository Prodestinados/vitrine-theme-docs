# Color Schemes

Customize your theme's 5 color schemes in **Theme Settings → Colors**.

## How to Edit

1. Go to **Theme Settings → Colors**
2. Each scheme has 5 editable colors: background, foreground, accent, button background, button text
3. Edit any color using the color picker
4. Changes apply everywhere that scheme is used

## Per-Section Usage

Every section has a **Color scheme** dropdown (1–5). Change it to apply a different scheme to that section.

## Tips

- Keep Scheme 1 as your default light scheme
- Reserve one scheme for dark/inverted sections (hero, CTA)
- Maintain sufficient contrast between background and foreground for accessibility (4.5:1 minimum)
