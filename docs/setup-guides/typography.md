# Typography

Vitrine supports separate heading and body fonts, each configurable in **Theme Settings → Typography**.

## Settings

| Setting | What it does |
|---------|-------------|
| **Heading font** | Font for all headings (h1–h6) |
| **Body font** | Font for paragraphs and general text |
| **Heading scale** | Size multiplier for headings: 80–150% (default 100%) |
| **Body scale** | Size multiplier for body text: 80–150% (default 100%) |

## Preset Defaults

| Preset | Headings | Body |
|--------|----------|------|
| Vitrine | DM Sans Bold | DM Sans Regular |
| Runway | Bebas Neue | Work Sans |
| Salon | Cormorant | Lato |

## Tips

- Increase heading scale to 120–130% for more dramatic typography
- Use Google Fonts or Shopify's built-in font library
- Font changes apply globally across all sections
