# Social Media Links

Add your social media profiles in **Theme Settings → Social media**.

## Supported Platforms

Enter the full URL for each platform:
- Facebook, Instagram, TikTok, X (Twitter), Pinterest, YouTube, Snapchat, Tumblr, Vimeo

## Where They Appear

Social icons automatically appear in the **Footer** section when:
- You've entered at least one social URL in Theme Settings
- The footer's **Show social icons** setting is enabled (default: on)

## Tips

- Only platforms with URLs entered will show icons
- Icons use the section's color scheme for consistent styling
