# Navigation & Menus

## Creating Menus

Menus are managed in **Shopify Admin → Online Store → Navigation**, not in the Theme Editor.

1. Go to **Online Store → Navigation**
2. Click **Add menu** or edit an existing menu
3. Add menu items (links to collections, products, pages, etc.)
4. Save the menu

## Connecting Menus to the Theme

In the Theme Editor, open the **Header** section:

| Setting | What it does |
|---------|-------------|
| **Menu** | Select your main navigation menu |

The footer also supports menu blocks — add a **Menu column** block and select a footer menu.

## Tips

- Keep your main menu to 4–6 top-level items
- Use nested items for dropdown menus
- Create a separate "Footer" menu for secondary links (FAQ, Contact, Policies)
