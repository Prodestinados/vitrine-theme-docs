# Custom Colors

## Can I use my own brand colors?

Yes. Go to **Theme Settings → Colors** and edit any of the 5 color schemes. Each scheme has:

- Background color
- Foreground (text) color
- Accent color
- Button background
- Button text color

Changes apply everywhere that scheme is used. Make sure to maintain sufficient contrast between background and text colors for accessibility (4.5:1 ratio minimum).
