# Page Speed

## How can I improve my store's loading speed?

Vitrine is built with performance in mind. To keep your store fast:

1. **Optimize images** — Use JPEG format and keep files under 500KB
2. **Limit sections** — Each homepage section adds weight. Use 6–8 sections maximum
3. **Use Shopify-hosted video** — External embeds (YouTube/Vimeo) add third-party scripts
4. **Minimize third-party apps** — Each app can add JavaScript that slows page load
5. **Enable lazy loading** — Vitrine does this automatically for below-the-fold images

Vitrine scores 75+ on Lighthouse Performance and 95+ on Accessibility out of the box.
