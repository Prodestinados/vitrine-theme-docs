# Translation

## Can I translate Vitrine to another language?

Yes. Vitrine uses Shopify's built-in translation system. All theme text is stored in locale files.

To translate:
1. Go to **Online Store → Themes**
2. Click **Actions → Edit default theme content**
3. Translate each string to your language

For multi-language stores, use Shopify Markets and the Translate & Adapt app.
