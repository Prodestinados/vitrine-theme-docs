# Mobile Responsive

## Is Vitrine mobile-friendly?

Yes. Vitrine is fully responsive and adapts to all screen sizes:

- **Desktop** (990px+) — Full multi-column layouts
- **Tablet** (750–989px) — Adjusted grids, typically 2 columns
- **Mobile** (under 750px) — Single-column stacked layout

All sections, product pages, and account pages work seamlessly on mobile devices. Use the Theme Editor's mobile preview to check your store.
