# Account Dashboard

Logged-in customers can access their account dashboard from the header account icon.

## Features

- **Order history** — View past orders with dates, status, and totals
- **Order details** — Click any order to see line items, billing, and shipping
- **Addresses** — Add, edit, and delete saved addresses
- **Default address** — Set a preferred shipping address

## Tips

- Customers can manage their own addresses without contacting support
- Order history shows fulfillment status automatically from Shopify
