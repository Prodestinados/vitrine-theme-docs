# Media & Images

Vitrine uses responsive images throughout, optimized for performance.

## Aspect Ratios

| Ratio | Dimensions | Use Case |
|-------|-----------|----------|
| **Portrait** | 3:4 | Fashion, hero images |
| **Square** | 1:1 | Product cards, grid items |
| **Landscape** | 4:3 | Blog, editorial |
| **Wide** | 16:9 | Video, hero sections |
| **Adapt** | Original | Preserves upload dimensions |

## Lazy Loading

All images below the fold use lazy loading for faster page performance. Hero images and above-the-fold content load immediately.

## Image Optimization Tips

- Upload images at 2x display size for retina screens
- Use JPEG for photographs (smaller file size)
- Use PNG only when transparency is needed
- Keep files under 500KB
- Shopify automatically generates responsive srcset sizes
