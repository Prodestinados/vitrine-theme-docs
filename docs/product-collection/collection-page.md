# Collection Page

The collection page displays all products in a collection with sorting options.

## Sorting Options

Customers can sort by:
- Best selling
- A–Z / Z–A
- Price: low to high / high to low
- Oldest / Newest

## Layout

Products display in a responsive grid that adjusts from 4 columns on desktop to 2 on mobile.

## Tips

- Set a collection image and description in **Shopify Admin → Products → Collections**
- Products inherit the image ratio from the Featured Collection section settings
